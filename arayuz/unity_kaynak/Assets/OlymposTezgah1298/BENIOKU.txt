3B tezgâh (OlymposTezgah3B, shader "Olympos/Tezgah 3B" — opak, ışıksız):
  Biçim: alçak sandık + üstte öne eğik teşhir tahtası. Ölçüler (karakter 1.8 birim için): genişlik 0.78, derinlik 0.42,
  ön yükseklik 0.59, arka yükseklik 0.99 (tahta ~44° eğik). karakterBoyu ile ölçeklenir. Pivot taban merkezi, forward = ön yüz.
  Dokular (Textures/3B, fotoğraflardan perspektif düzeltilerek): ust.png 512x374 (sancak + eşyalar), on.png 512x387 (asılı sancak),
  yan.png 330x512 (kırmızı perde; sağ yan = ayna; ARKA fotoğrafı yok -> yan doku).
  Kullanım: tezgah.Kur(konum, onYonu); tezgah.Kaldir();

Referans/tezgah_referans.jpg (önden) ve tezgah_yan_referans.jpg (yandan): kullanıcının ekran görüntüleri (2712 x 1220).

Grafik: mavi örtülü alçak sandık, üstünde kırmızı sancak (turuncu kenar, mavi göz arması), parşömenler, kılıç/hançer, 3 yüzük.
  İki görüntüden kesildi: Textures/tezgah.png (ÖN) 251 x 330 px, tezgah_yan.png (YAN) 193 x 246 px; renk/ışık/sıcaklık değiştirilmedi.
  Kamera tezgâhın önüne ~50°'den dik bakarsa ÖN, değilse YAN dokusu; ters taraf YAN'ın aynası.
Arka fon / saydamlık: tezgâh opak; dışı tamamen saydam (çim temizlendi), kenar 1.2 px yumuşak. Shader "Olympos/Tezgah Sprite" (alfa, ışıksız).
Boyut: ÖN — karakter 427 px -> yükseklik 0.773 karakter boyu (1.8 -> 1.39 x 1.06 birim); YAN — karakter 332 px -> 0.741 (iki ölçüm tutarlı).
Pivot: yere değdiği alt orta. Kameraya dönük (billboard). Tezgâhın ön yüzü (sancağın sarktığı taraf) = 'yon' / ebeveynin forward'ı.
Konum: kayıtta tezgâh, bakan karakterin ~1.2 karakter boyu sağındaydı; tezgâh çubuğu (OPEN / WHISPER) üstünde
  (çubuk Merchant / MerchantAlici paketlerinde). Kullanım: tezgah.Kur(konum, onYonu); tezgah.Kaldir();
Not: 3B model değil; iki açıdan alınmış görüntü (arka yüz görüntüsü yok). Görünüm geçişi ani (yumuşatma yok).
